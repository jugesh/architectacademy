# Architect Academy V2

A content-first technical architecture textbook. V1 at the repository root remains untouched.

## Structure
- `chapters/<part>/<chapter>/index.html`: standalone chapter pages
- `assets/book.css`: compact reading, Cornell and revision print styles
- `assets/book.js`: reading modes, print, glossary definitions
- `curriculum.json`: canonical chapter index and dependencies

Open `v2/index.html` directly or serve the repository with a static server. No build tools are needed for this initial foundation. Subsequent chapters follow the same folder convention.

## Editorial standard
Explain why, how, when, when not, operational failure modes, alternatives, and Java/AWS implications. Avoid decorative cards. Each chapter ends with substantive review questions. Print in Textbook, Cornell or Revision mode.
