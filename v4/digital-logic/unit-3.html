Basic Computer model

Mano’s Basic Computer is a teaching architecture with a 4096-word memory, 16-bit words and a single accumulator. An instruction code assigns bits to an operation and its operands or addressing information. This model’s layout is specific to the Basic Computer.

RegisterWidth and use
AR, PC12 bits each. AR holds the memory address. PC holds the next instruction address.
IR, DR16 bits each. IR holds the current instruction. DR holds a data operand from memory.
AC, TR16 bits each. AC holds operands and ALU results. TR holds temporary data.
INPR, OUTR8 bits each. INPR receives input and OUTR supplies output.
E, SCE is a one-bit extension for carry and rotates. SC is a four-bit sequence counter decoded into timing steps.

Instruction cycle and timing

InstructionEffect after the effective address EA is known
AND, ADD, LDAAND combines AC with M[EA]. ADD adds M[EA] to AC and sends carry-out to E. LDA loads M[EA] into AC.
STA, BUNSTA stores AC into M[EA]. BUN replaces PC with EA.
BSAStore the return PC in M[EA] and set PC to EA+1. An indirect BUN through the saved word returns.
ISZIncrement M[EA], store it back and skip the next instruction if the result is zero.

Register-reference examples are CLA (clear AC), CMA (complement AC), INC (increment AC) and HLT (stop). I/O instructions include INP (copy INPR into the low AC byte and clear FGI), OUT (copy the low AC byte into OUTR and clear FGO), SKI/SKO (test readiness and skip) and ION/IOF (enable or disable interrupts).

Worked indirect ADD. If IR contains 0x9020, I=1, opcode=001 and the address field is 0x020. If M[0x020]=0x0120, EA becomes 0x120 at T₃. At T₄ load DR from M[0x120]. At T₅ add DR to AC, update E with carry-out and clear SC. With AC=0xFFFF and DR=0x0002, AC becomes 0x0001 and E becomes 1.

I/O and interrupt cycle

FGI signals that input is available and FGO signals that output can accept a byte. With interrupts enabled by IEN, a ready flag can set the interrupt request. At the instruction boundary, the Basic Computer saves the return PC in M[0], starts the handler at address 1 and clears IEN and the interrupt request. The handler services the device, then returns via an indirect branch through M[0]. Modern processors generally save more context and may use several vectors.

Datapath, control and accumulator logic

The complete teaching computer has memory, registers, a shared internal bus, an ALU/shifter, I/O data and flag registers, and hardwired control. A bus multiplexer selects the source. Destination enables decide which registers capture it. A controller combines the decoded opcode, timing signal, addressing mode and flags to choose bus selects, memory read/write, ALU function and register enables.

To design the controller, write the register transfers for each instruction first. For example, decoded ADD at T₄ asserts memory read and DR load. ADD at T₅ selects addition, enables AC and E updates and resets SC. Check that every instruction ends by resetting the sequence or entering the interrupt path. AC input selection and load must agree so an inactive instruction leaves AC unchanged.

General registers and stacks

A general-register organization uses a register file with read ports to supply ALU operands and a write port to capture results. A control word can select two source registers, one destination and the ALU operation. A stack organization uses a stack pointer and LIFO storage. For a downward-growing, full stack of 4-byte words, PUSH decrements SP by 4 then stores, while POP reads then increments SP. Check for underflow and overflow.

Instruction formats can include opcode, register fields, immediate values, displacement or addressing-mode bits. A three-address instruction names destination and two sources. A two-address instruction reuses one operand as the destination. An accumulator instruction implies AC, and a zero-address stack ADD pops two operands and pushes their sum.

Common addressing modes

Implied / stackThe opcode implies an operand such as AC or the top of stack.

Data transfer instructions move values between registers, memory or I/O. Manipulation instructions perform arithmetic, bitwise logic or shifts. Program control instructions change execution order through jumps, conditional branches, calls, returns and traps. A call saves a return address in a link register, stack or other architecture-defined location.

RISC and CISC

RISC designs commonly favour load/store instructions, register-to-register arithmetic and regular instruction encodings. CISC designs commonly offer richer addressing modes, variable-length encodings and instructions that can combine memory access with computation. For example, a RISC-V sequence can load a word then add it to a register, while an x86 ADD can take a memory operand. RISC-V also has optional compressed encodings, and many x86 implementations decode instructions into internal micro-operations. The ISA defines visible behaviour. Pipeline depth, throughput and power depend on the implementation and workload.

Practice

What does instruction 0x302A do?

I=0, opcode=011 and EA=0x02A. STA stores AC to M[0x02A].

Why does BSA save the already incremented PC?

It points at the instruction after the call, where execution should resume on return.

What is the difference between immediate 20 and direct address 20?

Immediate uses the value 20. Direct addressing uses the data stored at address 20.
