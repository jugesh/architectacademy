Parallel processing, pipelines and vectors

Parallel processing overlaps work across hardware resources. Multicore processors can run independent threads (MIMD), while vector or SIMD hardware applies one instruction across multiple elements. Pipelining overlaps different stages of successive operations. If a fraction p of runtime can be sped up by a factor s, Amdahl’s law gives overall speedup 1/[(1−p)+p/s]. Accelerating 80% of runtime by 4× yields 2.5× overall.

An arithmetic pipeline for floating-point addition can align exponents and shift the smaller significand, add or subtract the significands, then normalize and round the result. Normalization can change the exponent. Pipeline registers carry intermediate values and flags forward. Once full, an ideal pipeline accepts a new independent operation each cycle.

For n independent operations through k stages, ideal execution takes k+n−1 cycles. With stage delays 2, 3, 4, 3 and 2 ns and 1 ns of register overhead, the pipeline clock period is 5 ns. A single instruction takes 25 ns and ten complete in 70 ns, assuming no stalls. Ideal steady-state throughput is one completion every 5 ns.

A vector add can express C[i]=A[i]+B[i] over a chunk of elements using vector loads, an add and a store. Hardware processes elements across lanes, possibly over several cycles. A mask or shorter vector length handles the tail. Memory bandwidth and noncontiguous access can limit gains.

Input-output organization

Peripheral devices include keyboards, displays, storage and network adapters. An I/O interface mediates between the bus and device using data, status and control registers, buffers and timing logic. With memory-mapped I/O, load/store instructions access device registers at assigned addresses. Isolated I/O uses a separate I/O address space or instructions.

Asynchronous transfer connects sides without a shared transfer clock. A strobe indicates when to sample and relies on timing assumptions. A request/acknowledge handshake lets the receiver respond when ready. In one four-phase handshake, the sender holds data stable and raises REQ, the receiver captures it and raises ACK, then the sender lowers REQ and the receiver lowers ACK. Clock-domain crossings still require suitable synchronization.

A priority interrupt controller arbitrates among simultaneous requests and can mask selected inputs. In a fixed-priority daisy chain, the first requesting device in acknowledgement order wins. A parallel priority encoder can select from multiple request lines and identify a vector. Pending lower-priority work may starve if higher-priority requests keep arriving.

Arithmetic algorithms

Unsigned shift-and-add multiplication

Read the multiplier from least significant bit upward. If bit i is 1, add the multiplicand shifted left by i. Use a 2n-bit product for two n-bit operands. For 1011₂ × 0110₂, bits 1 and 2 are set. Add 00010110₂ + 00101100₂ = 01000010₂ = 66₁₀.

Booth’s signed multiplication

In radix-2 Booth, start with accumulator A=0, multiplier Q and an extra bit q₋₁=0. Inspect (Q₀,q₋₁). On 01 add the sign-extended multiplicand M to A. On 10 subtract M. On 00 or 11 hold. Then arithmetic-right-shift the joined (A,Q,q₋₁), extending the sign of A. Repeat n times for an n-bit multiplier. Use n+1 bits for A and sign-extended M to handle the most-negative n-bit multiplicand. Read the low 2n bits of (A,Q) as the product.

Integer division

Restoring division starts with remainder 0 and reads dividend bits from most to least significant. Shift the remainder left and bring down the next bit. Subtract the positive divisor. If the result is negative, restore by adding the divisor back and emit quotient bit 0. Otherwise keep the result and emit 1. For 1101₂ ÷ 0011₂, the remainder after each processed bit is 1, 0, 0, 1, with quotient bits 0, 1, 0, 0. The result is 4 remainder 1. In non-restoring division, shift in the next bit and subtract the divisor if the old remainder was nonnegative. Add it if the old remainder was negative. Emit 1 when the new remainder is nonnegative and 0 otherwise. After the last bit, add the divisor once if the remainder is negative. Reject division by zero. For signed division, check the ISA’s rounding and remainder conventions.

Floating-point representation

IEEE 754 binary32 uses 1 sign bit, 8 exponent bits with bias 127 and 23 fraction bits. Binary64 uses 1, 11 and 52, with bias 1023. A normal number is (−1)s × (1+fraction) × 2E−bias. An exponent field of zero represents signed zero or subnormals, with a leading 0 and exponent 1−bias. An all-ones exponent represents infinity with a zero fraction and NaN with a nonzero fraction.

For 5.75₁₀, 101.11₂ = 1.0111₂ × 2². The binary32 sign is 0, the biased exponent is 129 or 10000001₂, and the fraction begins 0111 with trailing zeros. Many decimal fractions require rounding, including 0.1 in binary.

Memory organization

Associative memory or content-addressable memory (CAM) searches by content and returns a match or its location. A conventional memory is indexed by address. Fully associative lookup can compare tags in parallel, which is useful in small structures but costs hardware and power.

A cache holds copies in lines. A direct-mapped cache gives each block one possible line. A set-associative cache gives it a set of possible ways. A fully associative cache lets a block go anywhere. Lookup checks the tag and valid bit. A write-through policy updates the next level on every write. Write-back marks a line dirty and writes it later, such as on eviction. Write allocation on a miss is a separate policy.

Worked mapping. In a 1 KiB direct-mapped cache with 16-byte lines and 32-bit byte addresses, there are 64 lines, so the address has 4 offset bits, 6 index bits and 22 tag bits. For 0x1234, the offset is 4, the index is 35 and the tag is 4. If hit time is 1 ns, miss rate is 5% and extra miss penalty is 60 ns, average access time is 1+0.05·60=4 ns.

Virtual memory gives processes address spaces and enforces isolation and protection. On a TLB miss, a hardware or software page-table walk may find a present mapping and refill the TLB. Missing or forbidden mappings cause faults. The operating system can resolve a valid demand fault by allocating or loading a page. An invalid or forbidden access may terminate the process. With 4 KiB pages, virtual address 0x1234 has VPN 1 and offset 0x234. If page 1 maps to frame 0xA, the physical address is 0xA234.

Practice

How many cycles do 20 independent instructions need on an ideal five-stage pipeline?

5+20−1=24 cycles.

Does a TLB miss necessarily cause a page fault?

No. A present, permitted mapping can be loaded from the page table and put into the TLB.

What is the quotient and remainder for 10111₂ ÷ 100₂?

101₂ remainder 11₂, since 23=5·4+3.

Why use DMA for a large storage read?

The controller transfers the block into memory while the CPU can do other work. Setup and completion still involve the CPU.
