Digital Logic and Computer Organization

Start with logic gates and binary numbers, build registers and a CPU, then study how pipelines, I/O and memory work together. Each unit includes worked examples, diagrams and practice with answers.

Unit I · Digital principles and number systems

Boolean laws, Karnaugh maps, base conversions, arithmetic and binary codes.

Unit II · Circuits, registers and counters

Adders, subtractors, data routing, flip-flops, parallel loading, shift registers and binary counters.

Unit III · Basic computer and CPU

Instruction execution, register transfers, accumulator design, addressing modes and RISC/CISC.

Unit IV · Pipelines, I/O, arithmetic and memory

Pipeline hazards, vector processing, interrupts and DMA, arithmetic algorithms and the memory hierarchy.

Textbooks and open reading

  • Digital Design, 6th ed., M. Morris Mano and Michael D. Ciletti. Chapters 1–3 for representations and minimization, and 4–6 for combinational and sequential circuits. Pearson
  • Computer System Architecture, revised 3rd ed., M. Morris Mano and Rajib Mall. Chapters 6 and 9 for the Basic Computer and CPU, and 10–13 and 15 for pipelines, arithmetic, I/O, memory and peripherals. Pearson
  • Computer Organization and Design RISC-V Edition, 2nd ed., David A. Patterson and John L. Hennessy. Chapters 2–5 connect instructions, arithmetic, processor design and memory hierarchy. Morgan Kaufmann
  • The Elements of Computing Systems, Noam Nisan and Shimon Schocken. Projects 1–5 build gates, arithmetic, memory and a small computer. Nand to Tetris course materials
  • Computation Structures, MIT 6.004. Lectures 2–8 cover logic, state and timing. Lectures 15–19 cover caches, virtual memory, devices and interrupts. MIT OpenCourseWare lecture notes
