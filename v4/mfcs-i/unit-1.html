Sets

A set is a collection of distinct elements. Order and repeated occurrences do not affect equality. Write x ∈ A for membership and |A| for cardinality. Describe sets by listing elements, such as {2, 4, 6}, or by a rule, such as {x ∈ ℤ | 2 ≤ x ≤ 6 and x is even}.

A ⊆ B means every member of A belongs to B. A ⊊ B additionally requires A ≠ B. The empty set ∅ is a subset of every set. The power set ℘(A) contains all subsets of A and has 2|A| elements for finite A. For A = {1, 2}, ℘(A) = {∅, {1}, {2}, {1, 2}}. In particular, ∅ and {∅} have different sizes.

Use A = {1, 2, 3}, B = {3, 4} and U = {1, 2, 3, 4, 5} in the following examples.

To prove a set identity, compare the membership conditions. For example, x lies outside A ∪ B exactly when it lies outside both sets, so it belongs to Aᶜ ∩ Bᶜ.

The Cartesian product A × B is the set of ordered pairs (a, b) with a ∈ A and b ∈ B. For A = {1, 2} and B = {x, y}, the product is {(1, x), (1, y), (2, x), (2, y)}. For finite sets, |A × B| = |A| · |B|. Swapping the sets swaps the pair coordinates.

Relations

A binary relation from A to B is any subset of A × B. A relation on A is a subset of A × A. Write xRy when (x, y) ∈ R. Examples on A include the empty relation, the universal relation A × A, and the identity relation Δ = {(a, a) | a ∈ A}. The inverse relation R⁻¹ reverses every ordered pair.

A partial order is reflexive, antisymmetric and transitive. Set inclusion is a partial order, since some subsets can be incomparable. A total order is a partial order in which every pair is comparable, as with ≤ on integers. Equality is both symmetric and antisymmetric.

Equivalence relations and partitions

An equivalence relation is reflexive, symmetric and transitive. Its class [a] contains all x related to a. The classes form a partition. They are nonempty, pairwise disjoint and cover the set. Conversely, a partition defines an equivalence relation by placing two elements in relation when they lie in the same block.

On {0, 1, 2, 3, 4, 5, 6, 7}, define aRb when 3 divides a − b. Zero is divisible by 3, negating a multiple preserves divisibility, and adding two multiples preserves it. The three classes are {0, 3, 6}, {1, 4, 7} and {2, 5}.

Closures

A closure is the smallest relation containing R that has the desired property. The reflexive closure is R ∪ Δ. The symmetric closure is R ∪ R⁻¹. The transitive closure R⁺ contains pairs connected by a directed walk of positive length. The reflexive transitive closure R* also includes length-zero walks, so R* = R⁺ ∪ Δ.

For the matrix example, add (1, 1), (2, 2), (3, 3) for the reflexive closure. Add (2, 1), (3, 2) for the symmetric closure. Add (1, 3) for the transitive closure. Compute each closure starting from the original R.

Warshall’s algorithm

Start with the Boolean adjacency matrix. After iteration k, T[i, j] is true when i reaches j via a positive-length walk whose internal vertices are among the first k vertices. A walk is preserved if already known, or discovered by joining a walk from i to k with one from k to j.

T = copy of the adjacency matrix
for k = 1 to n:
    for i = 1 to n:
        for j = 1 to n:
            T[i, j] = T[i, j] OR (T[i, k] AND T[k, j])
return T

For 1 → 2 → 3, iteration k = 2 sets T[1, 3] to true. The final rows are (0, 1, 1), (0, 0, 1) and (0, 0, 0). Keep k in the outer loop. The algorithm uses O(n³) time and O(n²) matrix space. Set the diagonal to true at initialization when computing R*.

Functions

A function f from A to B gives each element of its domain A exactly one value in its codomain B. Its range is f(A), the set of values it actually produces. For f(x) = x² from ℝ to ℝ, the domain and codomain are ℝ, and the range is [0, ∞).

TypeTestExample
InjectiveEach codomain element has at most one preimage.x ↦ 2x from ℤ to ℤ
SurjectiveEach codomain element has at least one preimage.x ↦ x² from ℝ to [0, ∞)
BijectiveEach codomain element has exactly one preimage.x ↦ 2x + 1 from ℝ to ℝ

Composition applies functions right to left. In symbols, (g ∘ f)(x) = g(f(x)), provided the outputs of f lie in the domain of g. If f(x) = 2x + 1 and g(x) = x², then (g ∘ f)(x) = (2x + 1)² while (f ∘ g)(x) = 2x² + 1.

A function f from A to B has a two-sided inverse f⁻¹ from B to A exactly when f is bijective. Solve y = 2x + 1 for x to get f⁻¹(y) = (y − 1)/2 over ℝ. Verify both compositions give their respective identities. An injective function can also be inverted on its range.

Practice

How many subsets of {1, 2, 3, 4} contain 1?

8. Including 1 is fixed, and each of the three other elements has two choices.

What is the transitive closure of {(a, b), (b, a)} on {a, b}?

All four ordered pairs. The two-step walks a → b → a and b → a → b create the diagonal pairs.

What changes if f(x) = x² is defined from [0, ∞) to [0, ∞)?

It becomes bijective. Each y ≥ 0 has the unique nonnegative preimage √y, so f⁻¹(y) = √y.
