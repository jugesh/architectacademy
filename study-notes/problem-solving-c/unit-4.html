1. Modular problem solving

Divide a program into cohesive functions with clear contracts. Top-down: start with the overall task and refine it into functions. Bottom-up: build tested reusable functions and combine them. Recursion solves a problem through smaller instances of itself; it requires a base case and progress toward it.

int factorial(int n);          // prototype
int factorial(int n) {        // definition
    if (n <= 1) return 1;     // base case
    return n * factorial(n-1);
}

return exits the function and optionally supplies a value. Recursion uses O(n) stack frames for factorial versus O(1) space iteratively; large n also overflows integer types.

2. One-dimensional arrays

int a[] = {4, 2, 4, 7, 1};
int n = sizeof a / sizeof a[0];
int sum = 0, min = a[0], max = a[0];
for (int i=0; i<n; ++i) {
    sum += a[i];
    if (a[i] < min) min = a[i];
    if (a[i] > max) max = a[i];
}
double avg = (double)sum / n;

Indices range from 0 to n−1; bounds are not automatically checked. Median: sort and take middle value (or mean of two middle values). Mode: most frequent value; ties can produce multiple modes. Sorting before counting runs can simplify mode finding.

3. Searching and sorting

Sequential search: compare each element, O(n) worst case, works unsorted. Binary search: compare the middle and halve a sorted interval, O(log n) worst case.

int binary_search(const int a[], int n, int key) {
    int lo=0, hi=n-1;
    while (lo <= hi) {
        int mid=lo+(hi-lo)/2;
        if (a[mid]==key) return mid;
        if (a[mid]<key) lo=mid+1;
        else hi=mid-1;
    }
    return -1;
}

Selection sort: for each position i, locate the smallest item in i..n−1 and swap into i. O(n²) comparisons, O(1) extra space; generally not stable in its basic form.

4. Two-dimensional arrays and matrices

int a[2][3] stores two rows and three columns in row-major order. Use nested loops to read or print. Addition requires equal dimensions: C[i][j]=A[i][j]+B[i][j]. Multiplication requires A (m×k) and B (k×n), yielding C (m×n), with C[i][j]=Σ A[i][t]B[t][j]. Transpose swaps indices: T[j][i]=A[i][j]. Standard multiplication takes O(mkn) time.

5. Strings, operators and precedence

A C string is a char array terminated by '\0'. strlen counts characters before the terminator; strcmp compares lexicographically; strcpy/strcat require adequate destination capacity. Prefer length-checked approaches and verify buffers. Include <string.h>.

Common operators: sizeof, & (address), * (dereference), ?: (conditional), bitwise & | ^ ~ << >>. Rough precedence high→low: postfix, unary, multiplicative, additive, shifts, relational, equality, bitwise, logical, conditional, assignment, comma. Assignment is right-associative; most arithmetic operators are left-associative. Parenthesize when in doubt. Precedence is not the same as operand evaluation order.

Fix root causes, then rerun regression tests.

Explain recursion versus iteration, trace binary search, perform selection-sort passes, calculate matrix products, distinguish strlen from array capacity and diagnose off-by-one errors.
