1. Digits and number properties

For a nonnegative integer n, n % 10 extracts the rightmost digit and n /= 10 removes it. To read left-to-right, find the largest power of ten ≤ n, then divide by it and reduce the divisor. Treat zero separately.

Primen ≥ 2; no divisor from 2 through floor(√n)

2. Worked C example: prime

#include <stdio.h>
int main(void) {
    int n, prime = 1;
    if (scanf("%d", &n) != 1) return 1;
    if (n < 2) prime = 0;
    for (int d = 2; d <= n / d; ++d)
        if (n % d == 0) { prime = 0; break; }
    printf("%s\n", prime ? "Prime" : "Not prime");
    return 0;
}

The bound d <= n/d avoids overflow from d*d. Runtime O(√n), auxiliary space O(1).

3. Streaming statistics with a sentinel

count ← 0; sum ← 0
read x
while x != -1:
    if count == 0: min ← x; max ← x
    else:
        if x < min: min ← x
        if x > max: max ← x
    sum ← sum + x; count ← count + 1
    read x
if count > 0: average ← sum / count
else: print "No data"

Use only count, sum, min, max and current input: O(1) space. Sentinel -1 must not be a valid data value; choose another termination scheme if it is. Use a sufficiently wide sum type.

4. C branching and loop control

if (score >= 90) grade = 'A';
else if (score >= 75) grade = 'B';
else grade = 'C';
switch (grade) {
  case 'A': puts("Excellent"); break;
  case 'B': puts("Good"); break;
  default: puts("Keep practising");
}

++i increments before yielding a value; i++ yields the old value then increments (likewise --). break exits the nearest loop/switch; continue skips to the next loop iteration. Avoid modifying the same scalar multiple times without sequencing.
