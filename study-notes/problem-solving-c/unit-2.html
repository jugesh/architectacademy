1. Control structures

Sequence: statements run in order (input, assignment, output). Selection: if / if–else chooses a path. Repetition: for, while and do–while repeat steps. Stacking places structures consecutively; nesting places one inside another.

read n
if n % 2 == 0: print "even"
else: print "odd"
for i = 1 to n: print i

2. Pseudocode and flowcharts

Pseudocode uses language-independent steps; flowcharts use an oval for start/end, parallelogram for input/output, rectangle for processing, diamond for decisions and arrows for control flow.

4. How computers represent data

Memory stores bits. Integers, real numbers, characters and text are interpreted according to type and encoding. For 8 bits, +5=00000101. Sign-magnitude −5=10000101; one's complement −5=11111010; two's complement −5=11111011. Sign-magnitude and one's complement have two zeros; two's complement has one zero and range −128..127 for 8 bits.

IEEE 754 binary32: 1 sign bit, 8 exponent bits (bias 127), 23 fraction bits; normalized value (−1)^s × (1.fraction) × 2^(exponent−127). For example 1.5 has sign 0, exponent 127 and fraction bits 1000… . Subnormals, ±∞, NaN and rounding require care. ASCII maps 0–127 to characters/control codes; Unicode assigns code points, encoded as UTF-8/UTF-16 etc. Unicode is not identical to UTF-8.

5. C essentials

Programming languages evolved from machine code (1GL), assembly (2GL), high-level languages (3GL), domain-oriented declarative languages (often called 4GL) to AI/constraint-oriented systems (sometimes called 5GL). C was developed at Bell Labs by Dennis Ritchie in the early 1970s. C is statically typed; “typeless” commonly refers to languages with weak/no explicit static type declarations, not a rigorous single category.

#include <stdio.h>
int main(void) { return 0; } // minimal program
#include <stdio.h>
int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 1;
    if (n > 0) printf("Positive\n");
    else printf("Not positive\n");
    for (int i=0; i<n; ++i) printf("%d ", i);
    return 0;
}

Common types: char, int, float, double, plus signed/unsigned and size modifiers. = assigns; == != < > <= >= compare; + - * / % perform arithmetic; && || ! implement logic. Integer division truncates toward zero; division by zero is invalid. while tests first; do { ... } while(condition); tests last. Translate pseudocode stepwise, compile with warnings (gcc -std=c11 -Wall -Wextra), test after each small change. Use descriptive names, braces, consistent indentation and boundary tests.
